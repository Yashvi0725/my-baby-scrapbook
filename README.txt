MY BABY SCRAPBOOK WEBSITE ♡

This is your responsive four-page romantic scrapbook. The four photos and four audio files are included and linked to their pages.

FILES
- index.html: scrapbook home page
- page1.html through page4.html: four photo + letter + music pages
- style.css: mobile and desktop layout
- photos/photo1.png ... photo4.png: your supplied photos
- songs/song1.mp3 ... song4.mp3: your supplied audio files

RUN IT
1. Extract the ZIP.
2. Open the folder in VS Code using File > Open Folder.
3. Install the Live Server extension if needed.
4. Right-click index.html > Open with Live Server.
5. Navigate through the pages and press Play in each audio player.

SONG ORDER
1. Can't Help Falling in Love — Elvis Presley
2. Nayan Ne Bandh Rakhi Ne
3. Aaja Piya Tohe Pyar Doon — Lata Mangeshkar
4. Rukh Se Parda

EDIT LETTERS
Open page1.html through page4.html and edit the paragraphs inside <article class="letter-paper">.

ONLINE SHARING
The audio files are included locally for this personal project. Ensure you have permission to use tracks if publishing online. A public website can be viewed by anyone with the link, so only publish private photos if you're comfortable sharing them. The site is responsive for phones and computers.
